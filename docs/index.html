Screen List Capturer

把屏幕上任何列表变成表格 —— 不写一行爬虫。

1 分 09 秒 · 1920×1172 · MP4 7.7 MB · 无音轨 · 在 macOS 上实录

这段视频没有被压缩成 GIF，是原始画质 —— 界面上的日志可以逐字看清， 支持拖动进度、倍速和全屏。

关键时间点

  • 00:30  列表到底，工具自己停下 —— 日志出现「滚轮请求 490px / 实滚 0px → 视为已到达列表末端」，并且这一帧不再保存

画面里在发生什么

  1. 标定：倒计时引导点出列表的左上角和右下角，屏幕上其他东西都不影响。
  2. 自动滚动 + 逐屏截图：小批量发送滚轮事件，每批用截图测出真实位移，不够就补发。
  3. 到底判定：每帧和上一帧做灰度比对（允许几个像素的纵向位移，避开弹性滚动回弹），画面不再变化就立刻停止。
  4. 打包：截图打包成 zip，配一份可直接粘贴给视觉大模型的提示词。

装起来

git clone https://github.com/Signal-M/screen-list-capturer.git
cd screen-list-capturer
pip install -r requirements.txt
python screen_list_capturer.py
